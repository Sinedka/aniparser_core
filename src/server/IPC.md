# IPC, версия 3

Контракт для внешних клиентов находится в корневом
[руководстве по подключению](../../INTEGRATION.md). В нём описаны транспорт,
команды, payload, события и обработка ошибок.

Общие разбор JSON Lines и диспетчер находятся в `ipc/protocol.hpp`,
валидация — в `ipc/request_validation.hpp`. Оба транспорта используют
один диспетчер. Устройство сервера, владение соединениями и порядок изменения
протокола описаны в [docs/SERVER.md](../../docs/SERVER.md).
