# Aniparser Core

Локальный сервер для поиска аниме, получения карточек и ссылок на видео,
ведения коллекций и хранения прогресса просмотра. Приложения подключаются к
серверу по JSON Lines через Unix-сокет или именованный канал Windows.

- [Подключение своего приложения](INTEGRATION.md) — самостоятельная инструкция
  со сборкой и запуском сервера, контрактом IPC и примером на Python. Её можно
  передать нейросети вместе с проектом клиента.
- [Документация реализации](DOCS.md) — архитектура, исходный код, кэш, хранение
  данных и проверки.
- [Терминальный клиент](tui/README.md) — запуск и управление Linux TUI.
